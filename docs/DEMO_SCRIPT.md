# Invento — Demo Video Script

**Total time:** 2:30

## Before Recording
- Close all other browser tabs
- Hide bookmarks bar (Ctrl+Shift+B)
- Zoom browser to 110% (Ctrl +)
- Make sure backend + frontend are running
- Seed data loaded (6 products, 3 warehouses)
- Start at login page

## Script

### [0:00 – 0:15] — Hook
Say:
"Meet Invento — a centralized inventory management system that replaces spreadsheets with real-time stock tracking. Know what stock exists, where it is, and what needs attention."

Show: Dashboard loaded with KPIs

### [0:15 – 0:40] — Dashboard
Say:
"Here's the real-time dashboard. Six key metrics: total products, low stock alerts, out-of-stock items, pending receipts, deliveries, and scheduled transfers. The weekly chart tracks stock activity across all warehouses."

Show: Scroll dashboard slowly, hover KPI cards

### [0:40 – 1:00] — Products
Say:
"Products are organized with SKU codes, categories, and reorder levels. Notice the low-stock warnings and healthy inventory pills. Stock is tracked per location, not just in aggregate."

Show: Click Products → search → open Add drawer briefly → close

### [1:00 – 1:25] — Receipt (Stock In)
Say:
"Let's receive stock from a supplier. I create a receipt, add products, and validate. The stock ledger updates instantly — this receipt added 50 chairs to Main Warehouse."

Show: Receipts → New Receipt → fill form → Validate

### [1:25 – 1:50] — Transfer (Location Move)
Say:
"Now I'll transfer stock between warehouses. Notice the before/after preview — total company stock stays the same, only the location changes."

Show: Transfers → New Transfer → show preview → Validate

### [1:50 – 2:10] — Delivery (Stock Out)
Say:
"Deliveries ship stock to customers. The system prevents negative stock — if I try to deliver more than available, it blocks me."

Show: Deliveries → show validation warning → fix → Validate

### [2:10 – 2:25] — Move History
Say:
"Every operation is logged in the audit trail. Receipts, transfers, deliveries, adjustments — with product, quantity, location, and the resulting stock."

Show: Move History → scroll through rows → click row → detail drawer

### [2:25 – 2:30] — Close
Say:
"Invento — personalized, accessible, and audit-ready inventory management. Built with Next.js, FastAPI, and PostgreSQL."

Show: Toggle dark mode → fade out

## Recording Tips
- Speak 20% slower than normal
- Pause 1 second between sections
- If you mess up, keep going (can trim in editor)
